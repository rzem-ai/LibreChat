# Win theme framework (summary)

This mirrors `win-theme-workshop-pack/references/framework.md`. Read that file instead if the `win-theme-workshop-pack` skill is installed alongside this one — this copy exists only so `win-theme-development` still works standalone.

## The four-part formula

1. **Client priority** — what the client must achieve or avoid, in their own language, traceable to a source.
2. **Why us** — what we bring that matters and is hard for a credible competitor to match.
3. **Proof** — a specific evidence, example or demonstration, never an unsupported assertion.
4. **Quantifiable benefit** — a baseline, a measure and a timeframe.

## Signal tiers

- **Primary** — stated explicitly, repeated, or used as evaluation/scoring criteria.
- **Secondary** — implied by a requirement, constraint or risk rather than stated outright.

## The seven-point final check

1. Why us — "The client should choose us because…"
2. What makes us different — "Unlike other bidders, we…"
3. What worries the client — "The client's biggest risk is… and we address it by…"
4. Strongest evidence — "Our strongest proof point is…"
5. Client outcome — "By choosing us, the client will be able to…"
6. Finish the sentence — "We don't just provide ___, we provide ___."
7. Competitive gap — "If we lose, what will the winning bidder have convinced the client of?"

### Believability test

If a competitor used this exact statement, would it still be believable? Yes → too generic, sharpen it. No → that's a real win theme.
