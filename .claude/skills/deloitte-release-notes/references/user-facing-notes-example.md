# 🚀 MyAssist NextGen Platform Update: New Improvements Ready for Testing! (v7.0.2)
📢 General We've just released a range of enhancements to improve MyAssist NextGen! Here's what's new 👇
 
🎓 MyAssist Academy
- A guided tour now walks you through key features the first time you log in, otherwise access the MyAssist Academy anytime (as often as you wish) via the 🎓 button in the bottom left.
- Rate the first Getting Started tour and leave feedback when you complete it - our team will take this into account when building out future tours!
🔗 Connectors
- SharePoint connectors now show a "Limited Access" label to reduce confusion. You can request access via the Feedback form at the bottom of the screen, if your use case is a good fit!
- You should no longer encounter errors when using Connectors in an Agent/as part of Agent Builder.
📚 Citations & Sources
- Citations no longer mess up your Artifacts or Code Snippets.
- Citation cards show the source's logo and publish/upload date.
- KX and DPN disclaimers are now combined into a single, clearer message.
🌐 Web Search
- Enable web search in Anthropic Global models.
💪 Skills
- DAIS skill is available for all users, but will only work with SharePoint Connector enabled.
- File editing skill available for use alongside Run Code - create and edit Office files like PPTX, DOCX.
- Skill uploads now work reliably when zipped on a Mac.
