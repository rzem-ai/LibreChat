# Deloitte Custom Changes

## Purpose

The purpose of this file is to track all the changes made by the Deloitte team to the [default LibreChat code base](https://github.com/danny-avila/LibreChat).

This includes:
1. Modifications to existing files.
2. Addition of new files.
3. Deletion of files.

This will allow us to facilitate easier merges with the upstream repository and ensure that we can maintain our customisations effectively, without accidentally overwriting them.

## How To

`deloitte/DeloitteCustomChanges.csv` is updated automatically after PRs are merged into `develop`, and entries are kept in alphabetical order by path.
