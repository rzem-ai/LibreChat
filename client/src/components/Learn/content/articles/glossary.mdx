## MyAssist terms

<Terms>
  <Term name="Chat" href="/learn/articles/myassist-introduction#what-myassist-helps-you-do">A single conversation with MyAssist. Everything you type, every file you share and every response you receive lives in that chat. A new chat starts with no memory of the last one, unless you use memory or a project.</Term>
  <Term name="Model">The AI engine that reads your input and writes a response. It knows nothing about you, your client or your work unless you give it that context in the chat. The model picker lets you choose between engines with different strengths.</Term>
  <Term name="Prompt" href="/learn/articles/write-an-effective-prompt#the-gcse-method">The instruction you send to the model. The more precisely you define the goal, context, source material and expected output, the less the model has to guess.</Term>
  <Term name="Saved prompt" href="/learn/articles/guides/prompts#what-it-is">A reusable instruction in your prompt library, available in any chat, such as “Rewrite this in plain English”. A prompt you type is written fresh each time. A saved prompt is written once and retrieved on demand.</Term>
  <Term name="File">A document you attach to a chat so the model can read and work with it alongside your prompt. Attach what you need for the task at hand. For sources you can’t or shouldn’t upload, use a connector instead.</Term>
  <Term name="Connector (MCP)" href="/learn/articles/guides/connectors#what-it-is">A secure, pre-approved link to an external source, such as a research database or business application, that MyAssist can query directly. MCP stands for Model Context Protocol, the standard behind these links. Use a connector when a file upload isn’t possible or practical.</Term>
  <Term name="Skill" href="/learn/articles/guides/skills#what-it-is">A packaged set of instructions that tells the model how to approach a specific task consistently. The skill defines the method and the model carries it out. A saved prompt stores your own shorthand, while a skill is a repeatable playbook you can share across a team.</Term>
  <Term name="SKILL.md">The instructions file every skill upload package must contain.</Term>
  <Term name="Environment" href="/learn/articles/myassist-introduction#tailor-your-environment">Everything an agent can see and use while it works, such as your files, approved connectors and skills. The model only works with what its environment gives it.</Term>
  <Term name="Agent" href="/learn/articles/guides/agents#what-it-is">A model working with instructions, skills, connectors and files to carry out a multi-step workflow. Two agents can use the same model and still behave differently, because their skills and connectors differ. A skill handles one task, and an agent coordinates several.</Term>
  <Term name="Handoff" href="/learn/articles/guides/multi-agent#handoffs">A setting that lets one agent transfer the conversation to a specialist agent when a task needs different expertise. You set it up under Advanced in Agent Builder.</Term>
  <Term name="Subagent" href="/learn/articles/guides/multi-agent#subagents">A smaller, specialist agent that a main agent calls on to complete one part of a workflow. It works in its own focused context and returns a summary to the main agent. You only talk to the main agent.</Term>
  <Term name="Artifact" href="/learn/articles/guides/artifacts#what-it-is">Something MyAssist builds that you can use, such as a diagram, microsite or calculator, rather than text to read.</Term>
  <Term name="Memory">What MyAssist remembers about you across conversations. You can review and manage it.</Term>
  <Term name="Project">A workspace that groups related conversations, keeping long-running or multi-session work organised and findable.</Term>
</Terms>

## AI terms

<Terms>
  <Term name="Agentic Ecosystem" href="/learn/articles/agentic-ecosystem#what-the-agentic-ecosystem-is">The shared foundation of models, data, governance, skills and connectors that agents are built on. MyAssist is how you reach it.</Term>
  <Term name="GCSE" href="/learn/articles/write-an-effective-prompt#the-gcse-method">Goal, Context, Source and Expectations: a four-part method for writing a clear prompt.</Term>
  <Term name="Proprietary model">An AI model built and controlled by a technology provider.</Term>
  <Term name="Open-source model">An AI model whose code is public, so organisations can inspect, modify and build on it.</Term>
  <Term name="Open-weight model">An AI model whose files you can download and run yourself, even if the code that built it isn’t public.</Term>
</Terms>
