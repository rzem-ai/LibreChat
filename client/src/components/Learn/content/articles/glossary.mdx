## MyAssist terms

Each entry says what the term is and how it relates to the ones before it.

<Terms>
  <Term name="Chat" href="/learn/articles/myassist-introduction#what-myassist-helps-you-do">A conversation with MyAssist, and the starting point for any task.</Term>
  <Term name="Model">The AI that reads your request and writes a response. It knows nothing about you or your work until you give it context. Each option in the model picker is a different model.</Term>
  <Term name="Prompt" href="/learn/articles/write-an-effective-prompt#the-gcse-method">The instruction you give a model. A clearer prompt gives the model less to guess.</Term>
  <Term name="Saved prompt" href="/learn/articles/guides/prompts#what-it-is">A short, reusable instruction you store in the library and add to any chat, such as “Make this shorter”. A chat is one conversation. A saved prompt keeps the instruction for next time.</Term>
  <Term name="File">A document you give MyAssist to work from. The model reads it alongside your prompt. A file is a document you upload, and a connector links to an approved system you can’t upload from.</Term>
  <Term name="Connector (MCP)" href="/learn/articles/guides/connectors#what-it-is">A secure link to an approved source, such as a research database or business system. It lets MyAssist use information a file can’t hold. MCP stands for Model Context Protocol, the standard these links use.</Term>
  <Term name="Skill" href="/learn/articles/guides/skills#what-it-is">Written instructions for doing one task the same way every time. A skill tells the model how to work. It doesn’t change which model runs. A prompt saves your own instruction, and a skill packages a playbook anyone on the team can follow.</Term>
  <Term name="SKILL.md">The instructions file every skill upload package must contain.</Term>
  <Term name="Environment" href="/learn/articles/myassist-introduction#tailor-your-environment">Everything an agent can see and use while it works, such as your files, approved connectors and skills. The model only works with what its environment gives it.</Term>
  <Term name="Agent" href="/learn/articles/guides/agents#what-it-is">A model set up for one job, with instructions, skills, connectors and files. Two agents can use the same model and still behave differently, because their skills and connectors differ. A skill handles one task, and an agent coordinates several.</Term>
  <Term name="Artifact" href="/learn/articles/guides/artifacts#what-it-is">Something MyAssist builds that you can use, such as a diagram, microsite or calculator, rather than text to read.</Term>
  <Term name="Memory">What MyAssist remembers about you across conversations. You can review and manage it.</Term>
  <Term name="Project">A folder that groups related conversations, so long-running work stays organised and findable.</Term>
</Terms>

## AI terms

<Terms>
  <Term name="Agentic Ecosystem" href="/learn/articles/agentic-ecosystem#what-the-agentic-ecosystem-is">The shared foundation of models, data, governance, skills and connectors that agents are built on. MyAssist is how you reach it.</Term>
  <Term name="GCSE" href="/learn/articles/write-an-effective-prompt#the-gcse-method">Goal, Context, Source and Expectations: a four-part method for writing a clear prompt.</Term>
  <Term name="Proprietary model">An AI model built and controlled by a technology provider.</Term>
  <Term name="Open-source model">An AI model whose code is public, so organisations can inspect, modify and build on it.</Term>
  <Term name="Open-weight model">An AI model whose files you can download and run yourself, even if the code that built it isn’t public.</Term>
</Terms>
