Start with Chat. Add another capability when you need more consistency, expertise, information or coordination.

## Chat

A conversation

Get help with a task, question or idea.

**What it does:** Helps you think, draft, summarise and explore in the moment.

**Use it when:**

- You need help with a one-off task or want to explore an idea
- You are not sure where to start

“Help me draft an email”

## Prompt

Saved instructions

Reuse prompts to deliver consistent results.

**What it does:** Captures prompts you want to use repeatedly, including your preferred structure, tone or output.

**Use it when:**

- You repeat similar instructions and want a consistent format
- You have found an approach that works well

“Always structure my weekly update as progress, risks, decisions and next steps.”

## Skill

An expert playbook

Apply a proven process to a specific task.

**What it does:** Brings together structured instructions, specialist guidance and a repeatable approach.

**Use it when:**

- The task follows a defined method and expert guidance improves the result
- The same process is used repeatedly

“Use the Proposal Review Skill to assess this proposal against our standard criteria.”

## Agent

A project coordinator

Coordinate a detailed process using a series of skills, tools and information sources.

**What it does:** Orchestrates multiple tasks to achieve a broader outcome. An Agent can use several skills and tools, with each one completing a different part of the process.

**Use it when:**

- The work involves a multi-step process using different skills, tools or information sources
- You want an end-to-end outcome rather than help with one task

“Research the client and prepare a briefing pack for tomorrow’s meeting.”

## File

The information

Provide documents and source material.

**What it does:** Gives MyAssist specific content to analyse, reference or transform.

**Use it when:**

- Your task relies on a document and needs a summary or analysis
- You want the response grounded in specific source material

Upload a proposal and ask: “Summarise the key risks and assumptions.”

## Connector

Access to other systems

Use information from approved enterprise sources.

**What it does:** Connects MyAssist to approved information that sits beyond the files you provide.

**Use it when:**

- The information is held in another approved system or enterprise source
- You need trusted organisational knowledge

“Search our approved knowledge sources for relevant guidance.”

## Artifacts

An artifact is a rich output that MyAssist can generate for you, such as a microsite, diagram, interactive tool or other structured content.

Use artifacts when you want MyAssist to create something you can interact with, refine and share, rather than just receive a text response.

**Examples:**

- Build an interactive workshop agenda
- Create a webpage or microsite
- Generate a process diagram
- Build a simple calculator or planning tool

Artifacts are outputs generated from Chat, a Skill or an Agent, rather than a separate capability.

## A simple example: preparing for a client meeting

See how each capability adds a different layer of support.

**1. Start with Chat**

“Summarise the key points from this meeting agenda and help me prepare three questions.”

Chat helps you complete the task in the moment.

**2. Save a Prompt**

“Use my preferred meeting preparation format every time.”

You reuse instructions that consistently work well.

**3. Use a Skill**

“Use the Client Meeting Preparation Skill.”

The Skill applies a proven preparation process, guidance and structure.

**4. Ask an Agent to coordinate the full process**

“Research the client and prepare a briefing pack for tomorrow’s meeting.”

An Agent is useful when the work is more detailed and requires a series of skills and tools. Instead of completing one task, the Agent coordinates the sequence and brings the outputs together.

- **Skill 1: Research the client** - Use research tools and approved sources, such as IBISWorld and the AFR, to gather company, industry and market insights.
- **Skill 2: Review what we know** - Use internal documents, previous meeting notes and other available information to add context.
- **Skill 3: Create the briefing pack** - Synthesise the research and internal context into a structured, executive-ready briefing.

**Outcome:** A client meeting briefing pack with key insights, discussion points, questions, risks and opportunities.

**5. Add Files**

Provide the agenda, previous meeting notes, proposal or client report. These materials give MyAssist specific context for the task.

**6. Use Connectors**

Bring in relevant information from approved enterprise knowledge sources and business systems.

**7. Create an Artifact**

“Turn the briefing pack into an interactive client dashboard.”

## Choose in seconds

- Need help with a task? Start with Chat.
- Need consistency? Use a Prompt.
- Need a proven process? Use a Skill.
- Need a detailed, multi-step process coordinated? Use an Agent.
- Need source material? Add a File.
- Need approved enterprise information? Use a Connector.

Still not sure? Start with Chat and add capabilities only when the task calls for them.
