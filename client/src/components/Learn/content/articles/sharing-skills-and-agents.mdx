---
title: Sharing skills and agents
updated: 21 October 2026
---

Share a skill or agent so others can find it and use it. You choose who can access it and what they can do with it.

## Share a skill

1. Select **Skills** from the side menu to open Skills.
2. Select **Created by me** and open the skill you want to share.
3. In the skill, select **Share**.
4. Search for the people you want to share the skill with, then select them. They must have logged in to MyAssist at least once.
5. Assign a permission level: Viewer, Editor or Owner. People can access and use the skill based on the permissions you grant.
6. Select **Save Changes** to share the skill with the selected people.

Once a skill is shared, the people you shared it with can find it by selecting **Skills**. It is listed under **Shared**. They may need to enable the skill by accessing it through the Skills tab and toggling it to Active.

## Share an agent

1. Select **Agent Builder** from the side menu to open Agents.
2. Open the drop-down menu, then search for and select the agent you want to share.
3. Scroll to the bottom of the Agent Builder form and select **Share**.
4. Search for the people you want to share the agent with, then select them. They must have logged in to MyAssist at least once.
5. Assign a permission level: Viewer, Editor or Owner. People can access and use the agent based on the permissions you grant.
6. Select **Save Changes** to share the agent with the selected people.

**Note:** Also share every skill the agent uses with the same people, by following the process above.
