A skill packages instructions, reference material and optional supporting files so MyAssist can complete a repeatable task in a consistent way.

## Choose how to build your skill

**Write skill instructions: Build directly in MyAssist**

Build directly in MyAssist by adding a name, description and Markdown instructions. This is a good option for a straightforward skill that does not need supporting files.

**Upload a skill: Package supporting material**

Create the skill as a structured folder containing a required SKILL.md file and any supporting folders, then compress the folder as a ZIP file for upload. Use this option when the skill relies on references, templates, assets or scripts.

**Use MyAssist to help: Draft or strengthen the skill**

Use the MyAssist Skill Builder skill (myassist-skill-builder) to develop a first draft including creating the SKILL.md file, or the Skill Refiner skill (myassist-skill-refiner) to review and strengthen an existing skill. Check and tailor the result before creating or uploading it.

## Plan the skill before you build

1. **Define the outcome:** State the task the skill should complete and the value it should provide.
2. **Set the trigger:** Explain when the skill should be used and, where useful, when it should not be used.
3. **Identify the inputs:** List what the user must provide, such as an audience, topic, source file or preferred format.
4. **Design the workflow:** Break the task into clear steps and decision points. Tell the skill when to ask for missing information rather than guessing.
5. **Describe the output:** Specify the structure, tone, level of detail and any mandatory sections or templates.
6. **Add guardrails:** Include source boundaries, quality checks, privacy considerations and constraints that keep the response fit for purpose.
7. **Test and refine:** Try realistic scenarios, including incomplete or ambiguous requests, then adjust the instructions where results vary.

## Write effective instructions in Markdown

Markdown is a lightweight way to structure plain text. It helps distinguish headings, steps, examples and rules without complex formatting. Use headings to separate ideas, numbered lists for ordered workflows, bullet lists for options or checks, and bold text sparingly to emphasise important labels. ## Zip and upload the skill

1. Open the root folder and confirm that SKILL.md is directly inside it.
2. Check that file names and folder names exactly match any paths used in SKILL.md.
3. Remove drafts, duplicate files and anything the skill does not need.
4. Compress the root folder into a single .zip file. When the ZIP is opened, it should contain one skill folder with SKILL.md and any optional supporting folders inside it.
5. In MyAssist, open Skills, choose Upload a Skill, select the ZIP file and follow the prompts to validate and create the skill.
6. Test the uploaded skill with representative requests and refine the instructions or package if the results are inconsistent.
