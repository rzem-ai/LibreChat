---
title: Save and share prompts
updated: 21 October 2026
---

Save a prompt you use often so you can reuse it in Chat, and share it so others can use it too.

## Create a prompt

1. Select **Prompts** from the side menu to open your prompt library and view the prompts available to you.
2. Select **Create prompt** to open the fields for a new reusable prompt.
3. **Add a prompt name:** Enter a short name that makes the prompt easy to find later. Example: Monthly project update.
4. **Enter the prompt instructions:** Describe what the prompt should do. Example: Create a concise leadership update for senior leaders using the current project information provided. Highlight progress, decisions, risks and next steps.

## Add variables

Type `{{variable_name}}` anywhere in the prompt instructions to create a placeholder for information that changes each time you run the prompt. When you run the prompt, you are asked to enter a value for each variable.

Example: when generating the Monthly project update, you are prompted to add a reporting period.

Select **Special variables** to insert dynamic details that update automatically when the prompt is used, such as the current date, current user, UTC date and time, or local date and time.

## Add details to help you find it

5. **Add a description (optional):** Explain what the prompt does and when to use it. Example: Creates a concise monthly project update for senior leaders, covering progress, decisions, risks and next steps.
6. **Add a command (optional):** Enter a short command to quickly find and launch the prompt. Example: Monthly Project Update.
7. **Select a category:** Choose the category that best matches the prompt's purpose. This helps organise the prompt and makes it easier to find. Example: Communications & Stakeholders for the Monthly Project Update prompt.
8. Select **Create Prompt** to save it to the prompt library, ready to use in MyAssist.

## Use a saved prompt

Turn on **Send prompts on select**, then select the prompt you want to use. The prompt is sent in your conversation.

Alternatively, type `/` into the chat message composer to bring up a shortcut search bar for finding your saved prompts.

## Share a prompt

1. Open the prompt and select **Share**.
2. Search for the people you want to share the prompt with, then select them. They must have logged in to MyAssist at least once.
3. Assign a permission level: Viewer, Editor or Owner. People can access and use the prompt based on the permissions you grant.
4. Select **Save Changes** to make the prompt available to the selected people.
