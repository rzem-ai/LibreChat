## What it is

A saved prompt is a short, reusable instruction that you store in your prompt library and add to any chat. It works as a shortcut for a steering move you’d otherwise retype. Keep each one to a single move, and write full briefs with [the GCSE method](/learn/articles/write-an-effective-prompt#the-gcse-method).

## Why it matters

Retyping the same instruction costs time, and the wording changes each time. A saved prompt keeps the wording the same, so you get consistent results without starting from scratch.

## Prompts worth saving

Save the steering moves you reach for most:

- Make shorter: rewrite the last response in half the words, keeping the key points
- Make more casual: rewrite the last response in a relaxed, friendly tone
- Make a plan: turn the last response into numbered steps with an owner and a date
- Explain for a new starter: rewrite the last response for someone new to the topic

## Create a prompt

You can also ask MyAssist to generate a prompt in a chat. Review it, then save it to your library.

1. Select **Prompts** from the side menu to open your prompt library.
2. Select **Create prompt** to open the fields for a new prompt.
3. Enter a short name you can search for later. Example: Make shorter.
4. Enter the prompt instructions. Example: Rewrite your last response in half the words. Keep the key points and any numbers.
5. Select **Create Prompt** to save it to the library.

Three optional fields help you find a prompt later:

- Description: what the prompt does and when to use it
- Command: a short command that finds and launches the prompt
- Category: the group that best matches the prompt’s purpose, such as Communications & Stakeholders

## Use a prompt in a chat

Use a saved prompt in either of these ways:

- Turn on Send prompts on select, then select the prompt. MyAssist sends it in your conversation.
- Type `/` in the message box to open a search for your saved prompts.

## Share a prompt

<SharingNote />

1. Open the prompt and select **Share**.
2. Search for the people you want to share with, then select them.
3. Assign a permission level: Viewer, Editor or Owner. People can use the prompt based on the permission you grant.
4. Select **Save Changes**.
