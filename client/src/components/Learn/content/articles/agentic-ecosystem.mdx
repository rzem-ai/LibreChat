MyAssist is built from three layers that build on each other: chats for one-off questions, skills for a prompt you want to reuse, and agents for a task that runs several steps on its own.

## Chats

A chat is the fastest way to get an answer. Use it when you are exploring an idea or need a quick draft.

## Skills

A skill packages a prompt once so you can reuse it across chats, instead of retyping instructions each time.

## Agents

An agent combines skills and connectors to complete a multi-step task, then reports back.
