### ✨ Simplified Buttons

In the chat composer, only see the buttons you need to see. Everything else (artefacts, run code, skills) is on by default.

### 📄 File Upload

Now, there's one streamlined upload. Your file will go to File Search and Run Code as required. You can also upload images.

### 💸 Balance

Users are allocated a daily usage balance. This resets every 24 hours, if you are using all your allocated balance.

### 🎓 MyAssist Academy

Access training materials and guided tours.

### 🤖 Model details

Hover on a model for information about cost, speed and intelligence.

### 🔗 Connector details

Hover on a connector for details about what it can do, and what it can't do!

### 🧠 Human-in-the-loop for memory

The agent will seek your approval before saving, editing or deleting a memory, so you can confirm what's important.
