## 💪 Skills

Creating, editing, or uploading a skill now shows a clear loading state while it's being reviewed. Long skill names also display properly on the edit page instead of being cut off.

## 🔗 Connectors

SharePoint file uploads are now faster and more reliable for larger files. If a Code Interpreter file fails to upload, you'll now get a clear message instead of it failing silently.

## 🌐 Web Search

Enabled web search in OpenAI models — now available in General Chat, Advanced Parameters, and Agent Builder.

## 🧠 Memory

Improvements to how MyAssist stores and recalls your saved memory data.
